# lectures-03-and-04-demo

## Homework 2: Styling Your Page

Open `index.html` in a web browser to view **Small Steps**, a walking journal.
Keep `styles.css` in the same directory so the linked styles load. No installation
or build step is required.

### Styling checklist

- **Linked CSS:** `index.html` links to the separate `styles.css` file in its head.
- **Selector types:** type selectors (`body`, `h1`), class selectors (`.note`,
  `.walking-kit`), and ID selectors (`#page-header`, `#field-notes`) style matching elements.
- **Box model:** all three `.note` cards have explicit margin, padding, and borders.
  The header and walking-kit panel also demonstrate these properties.
- **Color scheme:** deep blue and burnt orange are paired with warm neutral
  backgrounds for a consistent, readable design.
- **Visual coherence:** shared typography, spacing, and card styles unify the page;
  cards stack on smaller screens.
